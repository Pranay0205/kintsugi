# Student Data Export & Annotation Tool Setup

This README describes the steps to export student data and prepare the KC annotation tool for a new student.

## Overview

The process involves two main steps:

1.  **Export Student Data**: Extract the student's best attempts from the dataset into a JSON file.
2.  **Patch Annotation Tool**: Embed the exported student data and reference solutions into a standalone HTML file.

---

## Steps

### 1. Export Student Data

Run the `export_student_data.py` script. You must provide the `SubjectID` of the student.

```bash
# Set PYTHONPATH to project root to allow imports from utils/
PYTHONPATH=. /mnt/d/Projects/kintsugi/.venv/bin/python scripts/export_student_data.py --student <STUDENT_ID>
```

**Output:**

- JSON file: `results/annotation_tool/student_data_<STUDENT_ID>.json`

### 2. Prepare the Annotation Tool

Patch the base `kc_annotation_tool.html` with the student's data and reference solutions.

```bash
PYTHONPATH=. /mnt/d/Projects/kintsugi/.venv/bin/python scripts/patch_annotation_tool.py \
  --student-file results/annotation_tool/student_data_<STUDENT_ID>.json \
  --ref-file results/annotation_tool/reference_solutions.json \
  --html scripts/kc_annotation_tool.html \
  --output results/annotation_tool/kc_annotation_tool_student_<STUDENT_ID>.html
```

**Output:**

- Patched HTML: `results/annotation_tool/kc_annotation_tool_student_<STUDENT_ID>.html`

---

## Common Arguments

- `--student-file`: Path to the exported student JSON file.
- `--ref-file`: Path to `results/annotation_tool/reference_solutions.json` (generated by `generate_reference_solutions.py`).
- `--html`: Path to the base template `scripts/kc_annotation_tool.html`.
- `--output`: Desired path for the final HTML file.
